# skills

The agent skills I used every day.

## Skills

- **real-work** — Capture planning as a durable, resumable markdown plan: phased
  work with checkboxes, autonomous verification, and handoff summaries so a future
  agent can pick up with zero prior context.

## Install

Using [skills.sh](https://skills.sh):

```sh
npx skills@latest add Elfocrash/skills
```

This adds the skills to your agent. Once installed, the agent activates a skill
automatically when your request matches its description.
